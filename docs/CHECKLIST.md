# Что проверить перед публикацией

Отмечайте пройденное. Если пункт не прошёл, пришлите номер, что нажимали и
что увидели. Пункты с ⛔ блокируют публикацию.

Автоматика уже проверяет тесты, линтер, сборку, `--selftest` и суммы. Ниже то,
что может проверить только человек.

## Блокеры

- [ ] ⛔ exe скачивается с GitHub и запускается на машине без Python.
- [ ] ⛔ Окно открывается за 1-3 секунды, без консольного окна и ошибок.
- [ ] ⛔ Дамп открывается, пакеты видны, фильтры работают (раздел 3).
- [ ] ⛔ `SmartPCAPParser.exe --selftest` даёт «Итог: OK», код 0.
- [ ] ⛔ VirusTotal: 0-3 эвристики это норма для PyInstaller, больше 10
      разбираемся до публикации.
- [ ] ⛔ `git status` чистый, `dist/`, `backups/`, `release/` не в git.

## 1. Скачивание

- [ ] На странице релиза три файла: exe, zip, `SHA256SUMS.txt`.
- [ ] exe весит около 13 МБ и скачивается одним кликом.
- [ ] SmartScreen просит подтверждение, «Подробнее», «Выполнить в любом
      случае». README и релиз это объясняют.
- [ ] `certutil -hashfile SmartPCAPParser.exe SHA256` совпадает с суммой.
- [ ] zip распаковывается, внутри `SmartPCAPParser/` и рабочий exe.
- [ ] Прямая ссылка `.../releases/latest/download/SmartPCAPParser.exe` открывает
      последнюю версию.

## 2. Открытие файлов

- [ ] «Открыть файл» открывает дамп.
- [ ] `SmartPCAPParser.exe C:\путь\файл.pcap` открывает окно с файлом.
- [ ] Файл, брошенный на иконку exe, открывается.
- [ ] Файл, брошенный в окно, открывается (нужен `tkinterdnd2`).
- [ ] Путь с пробелами и кириллицей работает.
- [ ] Недавние файлы появляются в списке, открываются, пропавший исчезает.
- [ ] Несуществующий файл даёт понятное сообщение, окно живо.
- [ ] Мусорный `.pcap` из блокнота даёт понятную ошибку.
- [ ] Большой дамп: `python tools/bench.py --mb 40 --keep`, открыть
      `.bench/bench_40mb.pcap`. Есть прогресс, «Отмена» работает, окно не
      висит.
- [ ] Заголовок окна: `Smart PCAP Parser 1.9.1` и имя файла.

## 3. Команды

На `tests/sample_traffic.pcap`, 13 пакетов:

- [ ] `покажи http трафик` даёт `http` и 2 пакета.
- [ ] `покажи сайт example.com` даёт 3 пакета.
- [ ] `покажи сайт` даёт `(http or tls or dns)`.
- [ ] `пакеты с айпи 192.168.1.10` даёт `ip.addr==192.168.1.10`.
- [ ] `пакеты на порт 53` даёт `udp.port==53` или `tcp.port==53`.
- [ ] `только dns` даёт `dns`.
- [ ] Подсказка: понятная фраза зелёная, «привет как дела» красная с
      объяснением.
- [ ] `Enter` применяет, `Esc` сбрасывает.
- [ ] Клик по примеру подставляет текст, адрес выделен.
- [ ] Быстрые кнопки применяют фильтр сразу.
- [ ] Копирование фильтра кладёт в буфер `http and ip.addr==...`.
- [ ] Фильтр из буфера принимается Wireshark и даёт те же пакеты.
- [ ] Готовый фильтр как есть: `tcp.port==443` даёт 3 пакета, `frame.len >
      1000` крупные кадры, `tcp.flags.syn==1` только SYN.
- [ ] `tcp.analysis.retransmission` даёт сообщение со списком полей, а не
      пустую таблицу.

## 4. Таблица

- [ ] Сортировка по колонкам, включая номер кадра.
- [ ] `Ctrl+F`: «example», «80», «8.8.8.8» находятся, счётчик меняется,
      `Esc` снимает поиск.
- [ ] Страницы: кнопки и `Ctrl+PgUp`/`Ctrl+PgDn`, номер обновляется.
- [ ] «Показать все» на большом файле работает или честно говорит про лимит.
- [ ] Правая кнопка: «только от», «только к», «только порт», копирование.
- [ ] CSV открывается в Excel, колонки не склеены, кириллица читается,
      строк ровно столько, сколько найдено.
- [ ] `Ctrl+T` открывает поток TCP, на UDP пакете «Поток UDP».

## 5. Детали, потоки, статистика, вердикт

- [ ] Двойной клик: слои, флаги TCP, hex-дамп.
- [ ] Поток TCP: текст и HEX, переключение направлений, сохранение в файл.
- [ ] UDP: датаграммы по порядку, в заголовке `8.8.8.8:53`.
- [ ] Статистика: график с подсказкой, иерархия, разговоры, узлы, сайты.
- [ ] «Все пакеты / Найденные» меняет цифры и не падает.
- [ ] Вердикт: по-русски, находки, «Показать» применяет фильтр, «Подробнее»
      открывает текст, копирование работает.
- [ ] Вердикт на пустом и битом файле не роняет приложение.

## 6. Вид и настройки

- [ ] `Ctrl+L` переключает тему, всё читаемо в обеих.
- [ ] Масштаб Windows 125% и 150%: ничего не обрезано.
- [ ] Минимальный размер окна: элементы не наезжают.
- [ ] Иконка в заголовке и на панели задач.
- [ ] `F1` открывает справку, текст не обрезан, закрывается.
- [ ] Перезапуск сохраняет тему, размер окна, колонки, историю, недавние.
- [ ] Второй монитор: окно перетаскивается, всё рисуется.

## 7. Края

- [ ] Пустой pcap: сообщение, без падения.
- [ ] Файл больше 200 МБ: предупреждение о памяти, приложение отзывчиво.
- [ ] Второй файл без закрытия первого: таблица и статистика обновились.
- [ ] Закрытие окна во время чтения: без ошибок.
- [ ] Несколько «Отмена» подряд: без исключений.
- [ ] Запуск из `C:\Program Files`: настройки не сохраняются, но приложение
      работает.

## 8. Техническое

- [ ] `python tools/final_check.py`: версии, ссылки, файлы, git, всё PASS.
- [ ] `python -m tests.run_all`: 12 модулей, все OK.
- [ ] `python tools/check_exe.py dist/SmartPCAPParser.exe
      dist/SmartPCAPParser/SmartPCAPParser.exe`: оба OK.
- [ ] Версия `1.9.1` везде: `parser/__init__.py`, `--version`, свойства exe,
      заголовок окна, `CHANGELOG.md`.
- [ ] `git status` чистый, ветка `main`, тег `v1.9.1` не отправлен.
- [ ] README на GitHub: скриншот виден, таблица скачивания, ссылки живые.
- [ ] `LICENSE` и `CHANGELOG.md` на месте.
- [ ] В релизе exe, zip и суммы, описание объясняет SmartScreen.

## Если что-то не так

Пришлите номер пункта, что нажали, текст ошибки, файл
`%TEMP%\smartpcap_selftest.txt`, а для проблем с файлом сам дамп, если он не
секретный. Ещё версию Windows и масштаб экрана.

## Минимум на 10 минут

1. Скачать exe с релиза, открыть `sample_traffic.pcap`.
2. `покажи сайт example.com`, должно быть 3 пакета.
3. Открыть детали пакета и поток TCP.
4. Посмотреть статистику и вердикт.
5. Переключить тему, закрыть и открыть, настройки на месте.
6. `--selftest`, код 0.
7. Сверить SHA256.
8. Запустить на машине без Python.
9. VirusTotal.
10. Прочитать страницу релиза глазами пользователя.
