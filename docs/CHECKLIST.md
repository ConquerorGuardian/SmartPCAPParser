не прошёл — пришлите номер пункта, что нажали и что увидели (текст ошибки или
скриншот). Всё, что помечено ⛔, — блокер: без него не публикуем.

полезно увидеть своими глазами): 177 тестов, lint, сборка exe, `--selftest`,

## 0. Блокеры (⛔)

- [ ] ⛔ `SmartPCAPParser.exe` скачивается с GitHub и запускается **на машине без Python** (другой ПК, виртуалка или чистая учётка).
- [ ] ⛔ Окно открывается за 1–3 секунды, без консольного окна и без ошибок.
- [ ] ⛔ Файл `.pcap` открывается, пакеты видны, фильтры работают (см. раздел 3).
- [ ] ⛔ `SmartPCAPParser.exe --selftest` в консоли: «Итог: OK», код возврата 0.
- [ ] ⛔ Антивирус не съедает exe: загрузите файл на virustotal.com — 0–3 эвристических срабатывания от неизвестных движков это норма для PyInstaller; больше 10 — разбираемся до публикации.
- [ ] ⛔ В репозитории нет секретов и мусора: `git status` чистый, `dist/`, `backups/`, `release/` не попадают в git.

- [ ] Кнопка «Открыть файл» → диалог → дамп открывается.
- [ ] `SmartPCAPParser.exe C:\путь\файл.pcap` открывает окно сразу с этим файлом.
- [ ] Файл, перетащенный **на иконку exe**, открывается.
- [ ] Файл, перетащенный **в окно**, открывается (если установлен `tkinterdnd2`; без него остальное работает).
- [ ] Файл из папки с пробелами и кириллицей в пути (`D:\Мои дампы\тест 1.pcap`) открывается.
- [ ] Недавние файлы: после открытия появляются в списке под кнопкой, открываются одним кликом, пропавший файл исчезает из списка.
- [ ] Несуществующий файл: понятное сообщение, окно не падает.
- [ ] Мусорный файл (создайте `test.pcap` из блокнота с текстом): понятная ошибка, окно живо.
- [ ] Большой дамп: `python tools/bench.py --mb 40 --keep` → открыть `.bench/bench_40mb.pcap` (~237 000 пакетов). Есть полоска прогресса, кнопка «Отмена» реально отменяет, окно не висит.
- [ ] Заголовок окна после загрузки: `Smart PCAP Parser 1.9.1 — bench_40mb.pcap`.

## 3. Команды и фильтры (главное)

На тестовом дампе `tests/sample_traffic.pcap` (13 пакетов):

- [ ] `покажи http трафик` → фильтр `http`, 2 пакета.
- [ ] `покажи сайт example.com` → 3 пакета (HTTP Host, DNS, TLS SNI).
- [ ] `покажи сайт` → фильтр `(http or tls or dns)`.
- [ ] `пакеты с айпи 192.168.1.10` → `ip.addr==192.168.1.10`.
- [ ] `пакеты на порт 53` → `udp.port==53` (или tcp/udp — в зависимости от формулировки).
- [ ] `только dns` → `dns`.
- [ ] Подсказка под полем: понятная команда — зелёная, бессмысленная («привет как дела») — красная, с подсказкой что нужно.
- [ ] `Enter` применяет; `Esc` очищает и возвращает все пакеты.
- [ ] Клик по примеру подставляет текст и выделяет адрес/порт для замены.
- [ ] Быстрые кнопки (TCP, UDP, HTTP, TLS…) применяют фильтр сразу.
- [ ] Кнопка копирования фильтра кладёт в буфер строку вида `http and ip.addr==...`.
- [ ] Вставьте скопированный фильтр в Wireshark (если установлен) — он принимается и даёт те же пакеты.
- [ ] Сверьте 3–4 фильтра с tshark: `tshark -r tests/sample_traffic.pcap -Y "<фильтр>" | wc -l` даёт столько же строк, сколько приложение.
- [ ] Готовый фильтр Wireshark вставляется как есть: `tcp.port==443` даёт 3 пакета (HTTPS), `frame.len > 1000` — крупные кадры, `tcp.flags.syn==1` — только SYN.
- [ ] Неподдерживаемое поле (`tcp.analysis.retransmission`) даёт сообщение со списком поддерживаемых полей, а не пустую таблицу.

## 4. Таблица

- [ ] Выделение строки и `Ctrl+T` открывает поток TCP; на UDP-пакете — «Поток UDP».

## 5. Детали, потоки, статистика, вердикт

- [ ] Двойной клик по пакету: детали с заголовками (Ethernet/IP/TCP), hex-дамп, флаги TCP читаемы.
- [ ] Поток TCP: текст и HEX, переключение направлений, содержимое не пустое, окно закрывается без ошибок.
- [ ] UDP-обмен: датаграммы по порядку, заголовок окна содержит `8.8.8.8:53`.
- [ ] Статистика: график по времени с подсказкой при наведении, иерархия протоколов, разговоры, узлы, сайты и хосты.
- [ ] Переключение «весь файл / найденные» в статистике меняет цифры и не падает.
- [ ] Вердикт: текст по-русски, находки, кнопка «Показать» применяет нужный фильтр, «Подробнее» открывает полный текст, копирование работает.
- [ ] Вердикт на пустом/битом файле не роняет приложение.

## 6. Вид, темы, настройки

- [ ] `Ctrl+L` переключает тёмную/светлую тему; всё читаемо в обеих (включая график и таблицу).
- [ ] Масштаб Windows 125 % и 150 %: ничего не обрезано, шрифты не «мылятся».
- [ ] Минимальный размер окна: элементы не наезжают друг на друга.
- [ ] Иконка приложения видна в заголовке окна и на панели задач.

- [ ] Перезапуск: тема, размер окна, ширина колонок, история команд, недавние файлы — сохранились.
- [ ] Второй монитор: окно перетаскивается, всё отрисовывается.

## 7. Краевые случаи

- [ ] Пустой pcap (0 пакетов): понятное сообщение, без падения.
- [ ] Огромный файл (>200 МБ): предупреждение о памяти, чтение без тел пакетов, приложение остаётся отзывчивым.
- [ ] Открыть второй файл, не закрывая первый: таблица и статистика обновились, старые данные не смешались.
- [ ] Закрыть окно во время чтения большого файла: приложение закрывается без ошибок в консоли.
- [ ] Быстро нажать «Отмена» несколько раз подряд: без исключений.
- [ ] Запуск из папки, где нет прав на запись (например, `C:\Program Files`): настройки не сохраняются, но приложение работает без падений.

## 9. Если что-то не так

Пришлите:

1. номер пункта и что именно нажали;
2. текст ошибки целиком (или скриншот);
3. файл `%TEMP%\smartpcap_selftest.txt` (создаётся `--selftest`);
4. для проблем с открытием файла — сам дамп, если он не секретный (или его размер, тип, чем снят);
5. версию Windows и масштаб экрана.

Этого хватает, чтобы воспроизвести почти любую проблему.
