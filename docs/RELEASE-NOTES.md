# Smart PCAP Parser 1.9.1

Одна программа, один файл: превращает обычную фразу на русском в фильтр
Wireshark и сразу показывает подходящие пакеты. Wireshark, tshark и ИИ не
нужны — pcap/pcapng разбирается внутри.

## Как запустить

1. Скачайте **`SmartPCAPParser.exe`** (~13 МБ) — установка не нужна,
   Python не нужен.
2. Запустите двойным кликом.
3. Откройте дамп `.pcap`/`.pcapng` кнопкой «Открыть файл», перетащите файл
   в окно — или перетащите его прямо на иконку `SmartPCAPParser.exe`.
   Из консоли: `SmartPCAPParser.exe C:\dumps\capture.pcap`

SmartScreen может спросить подтверждение: exe не подписан сертификатом —
обычное поведение для небольших открытых проектов. Проверить сборку:

```
SmartPCAPParser.exe --selftest
```

Код возврата 0 и отчёт `%TEMP%\smartpcap_selftest.txt` означают, что всё
в порядке.

## Две сборки

| Файл | Когда брать |
| --- | --- |
| `SmartPCAPParser.exe` | обычный вариант: один файл, запуск ~1–2 с |
| `SmartPCAPParser-1.9.1-windows-x64.zip` | если политика или антивирус не дают запускать одиночный exe; стартует быстрее (~0,2 с) |

Целостность — `SHA256SUMS.txt`:

```
certutil -hashfile SmartPCAPParser.exe SHA256
```

## Что нового в 1.9.1

- exe одним файлом; версия в заголовке окна и в справке;
- имя открытого файла в заголовке окна;
- открытие дампа аргументом командной строки и перетаскиванием на иконку;

Полная история — [CHANGELOG.md](../CHANGELOG.md).

## Что умеет

- Фильтры из фраз: «покажи http трафик с айпи 192.168.1.10», «пакеты на
  порт 443», «только dns», «сайт example.com»;
- таблица пакетов, поиск, сортировка, страницы, экспорт CSV;
- детали пакета с hex-дампом, поток TCP и обмен UDP;
- статистика: график по времени, иерархия протоколов, разговоры, узлы,
  сайты и хосты;
- вердикт по файлу простыми словами с находками;
- тёмная и светлая темы, настройки и недавние файлы сохраняются.

## Ограничения

- pcap/pcapng читаются целиком в память (заголовки); тела TCP/UDP —
  по требованию, до 64 МБ на поток;
- в таблице до 500 000 строк, дальше — фильтр и поиск;
- вычислитель не поддерживает весь синтаксис Wireshark
  (`tcp.analysis.*`, `http.response.*`);
- экзотические типы кадров (ATM, MTP2, Frame Relay) не разбираются.
