# Антивирус и SmartScreen

## Почему Windows ругается

`SmartPCAPParser.exe` собран PyInstaller: один файл, внутри Python и
библиотеки, при запуске распаковывается во временную папку. Цифровой подписи
нет, она платная. Из-за этого эвристика Windows и антивирусов иногда считает
файл подозрительным, хотя это обычная сборка открытого кода.

Это не значит, что в файле что-то есть: исходники лежат рядом, сборка
повторяется одной командой.

## Что нажать при запуске

1. SmartScreen: «Подробнее», затем «Выполнить в любом случае». Один раз для
   файла, дальше Windows его не трогает.
2. Если скачали zip и Windows ставит метку «из интернета», снимите её до
   распаковки: правая кнопка по zip, «Свойства», «Разблокировать», «ОК».
   Или в PowerShell: `Unblock-File .\SmartPCAPParser-1.9.1-windows-x64.zip`.
3. Антивирус удалил файл: добавьте папку в исключения, возьмите версию
   папкой из zip (она не распаковывается при запуске) или запустите из
   исходников.

## Убедиться, что файл не подменили

```powershell
certutil -hashfile SmartPCAPParser.exe SHA256
```

Сравните с `SHA256SUMS.txt` из того же релиза. Сумма должна совпасть
посимвольно.

Ещё два способа:

- `SmartPCAPParser.exe --selftest` печатает `Итог: OK` и возвращает код 0;
- VirusTotal по хэшу, без загрузки файла: откройте
  `https://www.virustotal.com/gui/file/<хэш>` и вставьте 64 символа из
  `SHA256SUMS.txt`.

Одно-два срабатывания мелких движков на сборке PyInstaller это норма.
Если ругается больше десяти, напишите в issue с ссылкой на отчёт: разберёмся.

## Что сделано, чтобы ложных срабатываний было меньше

- нет UPX и других упаковщиков: файл не сжимается;
- нет обфускации и загрузки кода из интернета, программа работает офлайн;
- только стандартная библиотека Python и `customtkinter`, без tshark,
  Wireshark, pyshark и сетевых обращений;
- исходники и сборка открыты, exe собирается из тега автоматически;
- в релизе лежат контрольные суммы, а `--selftest` проверяет сам файл.

## Если не доверяете готовому exe

```powershell
pip install -r requirements.txt
python main.py
```

Или соберите сами:

```powershell
pip install -r requirements-dev.txt
python tools/build_exe.py
```

Результат появится в `dist\SmartPCAPParser.exe`, это будет ваш собственный
файл. Подробности в [CONTRIBUTING](../CONTRIBUTING.md).
