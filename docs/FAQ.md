# Частые вопросы

## Чем это отличается от Wireshark

Wireshark умеет всё, но фильтры там пишутся на его языке. Здесь вы пишете
фразу по-русски, приложение собирает фильтр, применяет его и показывает
результат. Этот же фильтр можно вставить в Wireshark.

Заменой Wireshark это не является. Дерева на пять тысяч полей, расшифровки
TLS и пересборки файлов тут нет. Задача скромнее: быстро понять, что лежит
в дампе.

## Нужен ли Wireshark или tshark

Нет. pcap и pcapng разбираются внутри на стандартной библиотеке Python.
Wireshark нужен, только если хочется вставить скопированный фильтр или
сверить цифры.

## Нужен ли Python

Для готового exe нет. Python нужен, если запускаете из исходников через
`python main.py` или `run.bat`.

## Почему SmartScreen ругается

Файл не подписан платным сертификатом. Нажмите «Подробнее», потом «Выполнить
в любом случае». Один раз на файл, дальше Windows его не трогает.

Предупреждение приходит из-за метки «файл скачан из интернета». Если архив
скачанный, снимите метку до распаковки: правая кнопка по zip, «Свойства»,
галочка «Разблокировать», «ОК». То же из PowerShell:

```powershell
Unblock-File .\SmartPCAPParser-1.9.1-windows-x64.zip
```

После этого распакованный exe запускается без окна. Совсем убрать
предупреждение у всех пользователей может только подпись сертификата
Code Signing, он платный и для открытого проекта не обязателен.

Проверить, что файл не подменили, можно по контрольной сумме:

```powershell
certutil -hashfile SmartPCAPParser.exe SHA256
```

Сравните с `SHA256SUMS.txt` из релиза. Ещё есть `SmartPCAPParser.exe
--selftest`, код возврата 0 означает, что всё в порядке.

## exe пишет «Could not create temporary directory»

Это сообщение загрузчика PyInstaller, не программы. Одиночный exe сначала
распаковывает себя во временную папку. В этой сборке распаковка идёт в папку
`tmp` рядом с exe, поэтому ошибка возможна только когда папка с программой
только для чтения: например, exe положили в `Program Files` или на диск с
защитой от записи.

Тогда либо скопируйте exe на рабочий стол, либо запускайте версию папкой из
zip: она не распаковывается совсем.

Если хочется проверить `%TEMP%` на всякий случай:

```bat
echo %TEMP%
mkdir %TEMP%\test123
```

Последняя команда должна пройти без ошибки.

## exe запускается и сразу закрывается

Сначала посмотрите файл `%TEMP%\smartpcap_crash.txt`: собранный exe без
консоли пишет туда трейсбек, если упал. Если файла нет, процесс не дошёл до
Python, обычно это антивирус, недоступный `%TEMP%` или битая загрузка.

Что помогает по порядку: проверить сумму файла, запустить
`SmartPCAPParser.exe --selftest` из `cmd` и посмотреть код возврата
(`echo %ERRORLEVEL%`), попробовать `SmartPCAPParser-portable.exe`, добавить
папку в исключения антивируса, запустить версию папкой из zip. Текст из
`smartpcap_crash.txt` приложите к issue.

## Куда уходят данные

Никуда. Приложение не ходит в сеть, не проверяет обновления и не собирает
статистику использования. На диск пишутся только настройки
(`~/.smartpcapapp/settings.json`), отчёт самопроверки в `%TEMP%`, если
запускали `--selftest`, и CSV, который вы сами сохранили.

## Какие форматы читаются

pcap, включая расширенные заголовки и наносекундные метки, и pcapng с
несколькими интерфейсами. Канальный уровень: Ethernet с VLAN, raw IP,
loopback, Linux SLL и SLL2. Дальше IPv4, IPv6, TCP, UDP, ICMP, ICMPv6, ARP,
DNS, TLS с SNI, HTTP.

Дампы с Windows, Linux и macOS подходят. Если кадры сняты в формате, который
не поддерживается (PPP, экзотический беспроводной), приложение скажет об
этом в вердикте, а не покажет пустую таблицу.

## Почему «пакеты на порт 443» дают `tcp.port==443`, а QUIC не находится

Порт 443 в большинстве случаев TCP. Для QUIC скажите прямо: «покажи quic»
или «покажи udp порт 443».

## Файл большой, приложение не зависнет

Заголовки читаются в память, тела TCP и UDP подгружаются по требованию, когда
открываете поток, до 64 МБ на поток. На файлах больше 25 МБ тела заранее не
читаются. В таблице держим до 500 000 строк, на дампах в миллионы пакетов
лучше работать фильтром и поиском.

## Что такое вердикт

Короткий разбор файла обычными словами: что за трафик, какие хосты и
протоколы, что выглядит странно. Это подсказка, куда смотреть, а не
приговор. У находки есть кнопка «Показать», она сразу применяет фильтр.

## Можно вводить готовые фильтры Wireshark

Да. Если текст похож на фильтр (`tcp.port==443`, `ip.addr==10.0.0.1 and
http`, `frame.len > 1000`), приложение применит его как есть. Незнакомое поле
не даст пустую таблицу: появится сообщение со списком поддерживаемых.
Список полей в [EXAMPLES.md](EXAMPLES.md).

## Как выгрузить результат

Таблица фильтруется и сохраняется в CSV кнопкой «CSV». Excel и LibreOffice
открывают файл без танцев с кодировкой.

## Почему фильтр не принимается в Wireshark

Приложение отдаёт стандартные имена полей, но старые версии Wireshark знают
их иначе. Пример: `tls.handshake.extensions_server_name` появился не сразу.
Версия 3.6 и новее подходит, если поле подсвечено красным, обновите
Wireshark.

## Как показать программу другу

Отправьте ему один `SmartPCAPParser.exe`, он самодостаточный. Предупредите
про SmartScreen. Если мессенджер или почта не пропускают exe, отправьте
архив `SmartPCAPParser-1.9.1-friend.zip`: внутри тот же файл и инструкция на
страницу. Собрать архив заново: `python tools/make_friend_kit.py`.

## Где взять пример дампа

В репозитории: `tests/sample_traffic.pcap`, 13 пакетов, и такой же pcapng.
Для более серьёзной проверки `python tools/fetch_samples.py` скачает корпус
с настоящими файлами.

## Как сообщить об ошибке

Через issue по шаблону: что нажимали, что ожидали, текст ошибки, версия
Windows. Если можно, приложите дамп. Про уязвимости пишите приватно, как
описано в [SECURITY.md](../SECURITY.md).
