# История изменений

Формат по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии по [SemVer](https://semver.org/lang/ru/).

## [1.9.1] — 2026-11-01

Сборка, которую можно скачать одним файлом.

### Добавлено

- `SmartPCAPParser.exe`, около 13 МБ. Скачал, запустил, Python не нужен.
- `SmartPCAPParser.exe dump.pcap` открывает окно сразу с этим файлом, файл,
  брошенный на иконку exe, тоже открывается.
- `SHA256SUMS.txt` рядом с файлами релиза.
- Версия в заголовке окна и в справке, там же ссылка на репозиторий.
- Имя открытого файла в заголовке окна.
- Готовый фильтр Wireshark можно вставить как есть: `tcp.port==443`,
  `ip.addr==10.0.0.1 and http`, `frame.len > 1000`. Незнакомое поле даёт
  список поддерживаемых, а не пустую таблицу.
- Из статистики можно вернуться к пакетам: правая кнопка или двойной клик по
  сайту, разговору или узлу применяет фильтр и открывает вкладку «Пакеты».
- Трейсбек упавшего exe пишется в `%TEMP%\smartpcap_crash.txt`: без консоли
  иначе не видно, что случилось.
- Одиночный exe распаковывается в папку `tmp` рядом с собой, а не во
  временную папку Windows. Это лечит ошибку «Could not create temporary
  directory» на машинах со сломанной переменной `%TEMP%`.
- Документация: `docs/FAQ.md`, `docs/EXAMPLES.md`, `CONTRIBUTING.md`,
  `SECURITY.md`, шаблоны issue.

### Исправлено

- `tools/build_exe.py --both` портил onefile: обе сборки шли в один `dist/`,
  и одиночный exe падал с кодом -1. Теперь у каждого варианта своя папка,
  результат копируется в `dist/` после сборки.
- `SHA256SUMS.txt` собирается по всему `dist/`, поэтому zip и exe всегда
  попадают в список вместе.

### Изменено

- `tools/build_exe.py` по умолчанию собирает один файл, папка через
  `--onedir`, оба варианта через `--both`. Перед сборкой чистятся `build/` и
  `dist/`: старый `build/` ломал onefile-сборку.
- Проверка сборки это `python tools/check_exe.py <exe>`, то же делает CI.
  `Start-Process -Wait` на onefile зависает, поэтому запуск идёт через
  subprocess с таймаутом.
- CI собирает оба варианта и прикрепляет их к релизу вместе с суммами.
- У exe без консоли вывод перенаправляется в «никуда»: `--version` и
  `--selftest`, запущенные двойным кликом, больше не падают.

## [1.9.0] — 2026-10-29

Понимает типовые фильтры из интернета, показывает имена сайтов, работает с
большими файлами, собирает поток UDP.

### Добавлено

- Вычислитель фильтров: числовые поля (`frame.len`, `frame.number`, `ip.ttl`,
  `ip.len`, `tcp.len`, `tcp.seq`, `tcp.ack`, `tcp.window_size`, `udp.length`,
  `icmp.type`, `icmp.code`), флаги TCP, сравнения `<`, `>`, `<=`, `>=`, наборы
  `in {…}`, `contains` и `matches`. Фильтры вида
  `tcp.flags.syn==1 and tcp.flags.ack==0` больше не падают.
- Имена из трафика: HTTP Host, TLS SNI, DNS-имя в пакете, в колонке Info, в
  деталях, в статистике и в вердикте. Команда «покажи сайт example.com».
- Дефрагментация IPv4 и IPv6, после сборки разбирается TCP или UDP.
- «Поток UDP»: датаграммы одного обмена в порядке захвата.
- Новые детекторы вердикта: скан портов, ICMP-ошибки, широковещательный
  шторм, самый активный узел. Всего десять.
- График трафика по времени с подсказкой, переключатель «Байты / Пакеты».
- Сохранение настроек: тема, геометрия окна, ширина колонок, история команд,
  последняя папка, область статистики (`~/.smartpcapapp/settings.json`).
- Протоколы: ICMPv6, IGMP, GRE, ESP, AH, OSPF, LLMNR, SSDP, DHCPv6, RADIUS,
  NetBIOS, BGP, XMPP, IRC, L2TP, IPsec (IKE).
- Тела TCP и UDP подгружаются по требованию, поэтому большие файлы не
  занимают память целиком.
- CLI: `--version`, `--selftest`, `--help` с примерами.
- Страницы таблицы по 5000 строк, `Ctrl+PgUp` и `Ctrl+PgDn`.
- Недавние файлы, до 8 путей.
- Полоска прогресса и кнопка «Отмена» при чтении больших дампов.
- Перетаскивание файла в окно, если установлен `tkinterdnd2`.
- `gui/app.py` разбит на модули `layout`, `table_view`, `stats_view`,
  `dialogs`, `theme`, `help_text`. Поведение прежнее.
- `pyproject.toml`, конфиг ruff, GitHub Actions для тестов и сборки по тегу,
  PyInstaller, иконка, `tools/backup.py`, `tools/bench.py`, golden-тесты.

### Исправлено

- «покажи сайт 192.168.1.1» больше не считает адрес именем сайта.
- Имена полей Wireshark вроде `http.host` не принимаются за домен.
- Отрицание в «не сайт example.com» не теряется.

## [1.8.0] и раньше

История до 1.9.0 велась без changelog. Было: разбор pcap и pcapng без внешних
зависимостей, команды на русском, потоки TCP, статистика, вердикт, поиск по
таблице, экспорт CSV, две темы, тесты.
