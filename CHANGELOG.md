# История изменений

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [1.9.0] — 2026-10-29

Большая доработка: приложение научилось понимать типовые фильтры из интернета,
показывать имена сайтов, работать с большими файлами и собирать потоки UDP.

### Добавлено

- **Вычислитель фильтров**: числовые поля (`frame.len`, `frame.number`,
  `ip.ttl`, `ip.len`, `tcp.len`, `tcp.seq`, `tcp.ack`, `tcp.window_size`,
  `udp.length`, `icmp.type`, `icmp.code`), флаги TCP (`tcp.flags.syn`, `.ack`,
  `.fin`, `.rst`, `.psh`, `.urg`, `.ece`, `.cwr`), сравнения `<`, `>`, `<=`,
  `>=`, наборы `in {…}`, `contains` и `matches`. Фильтры вида
  `tcp.flags.syn==1 and tcp.flags.ack==0` больше не падают.
- **Имена из трафика**: HTTP Host, TLS SNI, DNS-имя — в пакете, в колонке Info,
  в деталях, в статистике и в вердикте. Команда «покажи сайт example.com».
- **Дефрагментация IPv4 и IPv6**: фрагменты собираются в датаграмму, после чего
  разбирается TCP/UDP.
- **«Поток UDP»**: датаграммы одного обмена в порядке захвата.
- **Вердикт**: новые детекторы — скан портов, ICMP-ошибки, широковещательный
  шторм, самый активный узел (всего 10 детекторов).
- **График трафика** по времени с подсказкой при наведении, «Байты / Пакеты».
- **Сохранение настроек**: тема, геометрия окна, ширина колонок, история
  команд, последняя папка, область статистики (`~/.smartpcapapp/settings.json`).
- **Новые протоколы**: ICMPv6, IGMP, GRE, ESP, AH, OSPF, LLMNR, SSDP,
  DHCPv6, RADIUS, NetBIOS, BGP, XMPP, IRC, L2TP, IPsec (IKE).
- **Потоки**: тела TCP/UDP подгружаются по требованию для больших файлов.
- **CLI**: `--version`, `--selftest`, понятный `--help` с примерами.
- **Страницы таблицы**: результаты больше 50 000 строк листаются страницами
  по 5 000 (`Ctrl+PgUp`/`Ctrl+PgDn`, кнопки под таблицей) — «Показать все»
  больше не нужно, весь файл доступен.
- **Недавние файлы**: до 8 путей в списке под кнопкой «Открыть файл».
- **Прогресс и отмена чтения**: полоска прогресса и кнопка «Отмена» для
  больших дампов; `read_packets` принимает `progress` и `should_stop`.
- **Перетаскивание файла** в окно — если установлен `tkinterdnd2`
  (необязательная зависимость).
- **Структура проекта**: `gui/app.py` разбит на модули (`layout`,
  `table_view`, `stats_view`, `dialogs`, `theme`, `help_text`) — поведение
  прежнее, файлы по 100–950 строк.
- **Проект**: `pyproject.toml`, конфиг ruff, GitHub Actions (тесты и сборка
  exe по тегу), сборка exe через PyInstaller, иконка приложения, скрипты
  `tools/backup.py` и `tools/bench.py`, golden-тесты фильтров.

### Исправлено

- «покажи сайт 192.168.1.1» больше не считает IP именем сайта.
- Имена полей Wireshark (`http.host`) не принимаются за домен.
- Отрицание в «не сайт example.com» не теряется.

## [1.8.0] и раньше

История до 1.9.0 велась без changelog. Основное, что уже было: разбор
`.pcap`/`.pcapng` без внешних зависимостей, команды на русском, сборка
TCP-потоков, статистика, вердикт по файлу, поиск по таблице, экспорт CSV,
тёмная и светлая темы, тесты на всё перечисленное.
