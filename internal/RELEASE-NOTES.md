# Smart PCAP Parser 1.9.1

Одна программа, один файл. Пишете фразу по-русски, получаете фильтр
Wireshark и сразу видите пакеты. Wireshark, tshark и Python не нужны.

## Как запустить

1. Скачайте `SmartPCAPParser.exe`, около 13 МБ. Установка не нужна.
2. Запустите двойным кликом.
3. Откройте дамп кнопкой «Открыть файл», перетаскиванием в окно или бросьте
   файл на иконку exe. Из консоли: `SmartPCAPParser.exe C:\dumps\capture.pcap`

SmartScreen может спросить про запуск: сертификата у файла нет. Проверить
сборку можно так:

```
SmartPCAPParser.exe --selftest
```

Код 0 и отчёт `%TEMP%\smartpcap_selftest.txt` означают, что всё в порядке.

## Две сборки

| Файл | Когда брать |
| --- | --- |
| `SmartPCAPParser.exe` | обычный вариант, один файл, запуск за 1-2 секунды |
| `SmartPCAPParser-1.9.1-windows-x64.zip` | если политика запрещает одиночные exe, стартует за 0.2 секунды |

Целостность проверяется по `SHA256SUMS.txt`:

```
certutil -hashfile SmartPCAPParser.exe SHA256
```

## Что нового

- exe одним файлом, версия в заголовке окна и в справке;
- имя открытого файла в заголовке окна;
- открытие дампа аргументом и перетаскиванием на иконку;
- готовый фильтр Wireshark можно вставить как есть;
- суммы в `SHA256SUMS.txt`, проверка сборки в CI.

История версий в [CHANGELOG.md](../CHANGELOG.md).

## Что умеет

- фильтры из фраз: «покажи http трафик с айпи 192.168.1.10», «пакеты на порт
  443», «только dns», «покажи сайт example.com»;
- таблица пакетов, поиск, сортировка, страницы, CSV;
- детали пакета с hex-дампом, поток TCP, обмен UDP;
- статистика: график по времени, протоколы, разговоры, узлы, сайты;
- вердикт по файлу простыми словами, у находки есть кнопка «Показать»;
- тёмная и светлая темы, настройки и недавние файлы сохраняются.

## Ограничения

- заголовки читаются в память, тела TCP и UDP подгружаются по требованию, до
  64 МБ на поток;
- в таблице до 500 000 строк, на больших дампах работайте фильтром;
- вычислитель не знает весь синтаксис Wireshark: `tcp.analysis.*` и
  `http.response.*` не поддерживаются;
- ATM, MTP2 и Frame Relay не разбираются;
- расшифровки TLS нет.
