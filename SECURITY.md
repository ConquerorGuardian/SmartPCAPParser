# Безопасность

## Как сообщить об уязвимости

Не открывайте публичный issue, если проблема связана с безопасностью.

1. **GitHub Security Advisory** — вкладка Security → «Report a vulnerability»
   в репозитории (приватно).
2. Если этот способ недоступен — напишите мейнтейнеру через профиль
   `@Whitemoneydealer` на GitHub, без публичных деталей.

В письме: версия (`SmartPCAPParser.exe --version`), версия Windows, что
происходит, какой файл это вызывает (или его структура), ожидаемый эффект
(падение, зависание, чтение за границами, исполнение кода). По возможности —
минимальный воспроизводящий pcap.

Ответ: обычно в течение недели; исправление выходит обычным релизом, вы
будете упомянуты в `CHANGELOG.md`, если не попросите об обратном.

## Поддерживаемые версии

Исправления безопасности выпускаются для последней версии. Старые сборки не
патчатся — обновите exe, заменив файл (настройки сохраняются).

## Модель угроз

Приложение разбирает **недоверенные файлы**: дамп, полученный от кого угодно,
считается враждебным. Гарантии:

- нет сетевого доступа: приложение не ходит в интернет, не проверяет
  обновления, не отправляет телеметрию (проверяется на уровне кода, не только
  политики);
- нет исполнения данных из файла: содержимое пакетов отображается, но не
  интерпретируется как код или команды;
- все чтения структурированных данных проверяют границы буфера; битые длины,
  обрезанные заголовки и циклы ссылок не приводят к бесконечному циклу или
  чтению за пределами кадра;
- размеры и количества ограничены: тела потоков — до 64 МБ, строк в таблице —
  500 000, длина строк в деталях ограничена;
- pcapng-опции неизвестного типа пропускаются по их же длине, а не
  угадываются.

Вне области гарантий: расшифровка TLS (её нет), сетевые функции, сторонние
библиотеки — из внешних зависимостей только `customtkinter` (и опционально
`tkinterdnd2`).

## Что приложение пишет на диск

- `%APPDATA%\SmartPCAPParser\settings.json` — тема, размер окна, история
  команд, недавние файлы;
- `%TEMP%\smartpcap_selftest.txt` — отчёт самопроверки, только если вы
  запускали `--selftest`;
- CSV, который вы сами сохранили через экспорт.

Больше ничего. Файл настроек можно удалить в любой момент — приложение
создаст его заново с настройками по умолчанию.

## Проверка сборки

Сборка воспроизводима из исходников (`python tools/build_exe.py --both`).
Целостность скачанного файла проверяется по `SHA256SUMS.txt`; exe не подписан
коммерческим сертификатом, поэтому SmartScreen может предупредить — это
ожидаемо и описано в README.
