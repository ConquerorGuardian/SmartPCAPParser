# Безопасность

Нашли уязвимость, не открывайте публичный issue. Вкладка Security в
репозитории, кнопка «Report a vulnerability». Это приватно, вижу только я.
Если кнопки нет, напишите в профиль `@Whitemoneydealer` без подробностей.

В сообщении хватит версии (`SmartPCAPParser.exe --version`), версии Windows
и описания: что происходит и на каком файле. Небольшой дамп приложите, если
он не содержит чужих данных.

Отвечаю обычно в течение недели. Исправление выходит обычным релизом, ваше
имя будет в `CHANGELOG.md`, если не попросите иначе.

## Что можно ожидать

Дамп считается враждебным. Приложение не ходит в сеть, не исполняет данные
из файла, проверяет длины и смещения, ограничивает размеры (тела потоков до
64 МБ, строк в таблице до 500 000). Настройки пишутся только в
`~/.smartpcapapp/settings.json`, отчёт `--selftest` в `%TEMP%`.

Расшифровки TLS нет. Из внешних библиотек только `customtkinter` и
опционально `tkinterdnd2`.
